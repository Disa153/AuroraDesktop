# Aurora Desktop

**Aurora Desktop** — прототип нативного приложения для Windows, предназначенного для персонализации рабочего стола и создания собственной визуальной атмосферы.

Проект объединяет в одном интерфейсе атмосферные эффекты, настройки внешнего вида и концепцию панели быстрого запуска Dock. Приложение создаётся на **Python и PySide6** — это полноценная настольная программа, а не веб-страница.

## Возможности текущей версии

- **Главная страница** — обзор интерфейса и основных разделов Aurora Desktop.
- **Атмосферные эффекты** — анимированный предварительный просмотр снега, дождя, тумана, листьев, грозы и режима без эффекта.
- **Настройка эффектов** — регулировка интенсивности и скорости анимации.
- **Оформление** — выбор акцентной цветовой темы интерфейса.
- **Панель Dock** — предварительный макет панели с иконками приложений.
- **Настройки** — интерфейс параметров поведения и запуска приложения.

## Что ещё предстоит реализовать

Текущая версия — демонстрационный прототип интерфейса. Некоторые элементы пока показывают концепцию будущих функций:

- отображение погодных и визуальных эффектов непосредственно поверх рабочего стола Windows;
- полноценная панель Dock с запуском приложений;
- реальное сворачивание приложения в системный трей;
- сохранение настроек и запуск вместе с Windows.

Эти возможности не следует считать реализованными в текущей версии.

## Запуск из исходников

Понадобится Windows и установленный Python. Открой командную строку в папке проекта и выполни:

```bat
py -m pip install -r requirements.txt
py src\main.py
```

Либо запусти файл `run.bat` — он установит зависимости и откроет приложение.

## Сборка Windows EXE

Чтобы собрать исполняемый файл самостоятельно, запусти:

```bat
build_exe.bat
```

После успешной сборки файл появится по пути:

```
dist\AuroraDesktop\AuroraDesktop.exe
```
